## 2. 起動方法

### 必要なもの
- .NET 10 SDK

### Visual Studio から起動する
1. `StaffNavi.sln`（または `StaffNavi.slnx`）を開きます。
2. F5 キー（または「デバッグの開始」）で起動します。

### コマンドで起動する
```powershell
cd StaffNavi
dotnet run
```
起動したら、ブラウザで http://localhost:5037 を開きます。

## 4. 操作の流れ（デモの進め方）

初期状態では、スタッフ18名・6拠点の **2026年7月・8月分** が取込済みです。

1. **サンプルCSVを用意する**
   「CSV取込」画面で `勤怠実績_202609.csv`（9月分のダミーデータ）をダウンロードします。
2. **CSVを取り込む**
   ダウンロードしたファイルを選んで読み込みます。取込件数、エラー、要確認データ（打刻漏れ・休憩不足など）が表示されるので、内容を確認して「取込を確定」します。
   - 文字コードは Shift_JIS と UTF-8 のどちらでも読み込めます。
3. **勤務表で確認・補正する**
   要確認の日（赤色の行）の「補正」ボタンから勤務内容を直します。補正理由の入力は必須です。
4. **補正履歴を確認する**
   補正前・補正後の差分を確認できます。誤った補正は取り消せますが、記録は削除されずに残ります。
5. **賃金台帳を確認する**
   補正後の勤務実績で集計された結果を確認します。
6. **提出用資料を出力する**
   「提出資料出力」で帳票と対象月を選び、印刷またはPDFで出力します。補正した箇所に※印を付けるかどうかを選べます。
7. **スタッフナビゲーターに戻す（任意）**
   「提出資料出力」の「スタッフナビゲーター連携用CSV」から、補正後の勤怠を **勤怠データCSV（取込用）** として出力します。スタッフナビゲーターの「給与管理｜勤怠データCSVファイル取込」で、オプション「1行目を無視する」をONにして取り込みます。

### 取り込めるCSVの形式

1行目は項目名です。項目の並び順は自由です（項目名で判断します）。

| CSVの種類 | 項目 |
|---|---|
| 勤怠実績 | スタッフ番号、氏名、拠点、勤務日、勤務区分、出勤時刻、退勤時刻、休憩(分)、備考（備考は省略可） |
| スタッフ情報 | スタッフ番号、氏名、フリガナ、性別、生年月日、拠点、雇用区分、入社日、時給、通勤手当日額、住民税月額、扶養家族人数（生年月日・扶養家族人数は省略可） |

- スタッフ番号は **1〜8桁の数字** です。項目名が「社員番号」でも読み込めます。
- 勤務区分は「出勤」「休日出勤」「有給」「公休」「欠勤」のいずれかです。

### 出力できる資料

| 資料 | 形式 | 備考 |
|---|---|---|
| 勤務表（出勤簿） | 印刷／PDF | 日ごとの始業・終業・休憩・時間区分。補正箇所に※印 |
| 賃金台帳 | 印刷／PDF／CSV | スタッフナビゲーターと同じ様式。CSVは賃金台帳CSV形式（60項目・Shift_JIS） |
| 勤務実績集計表 | 印刷／PDF | 拠点・スタッフごとの月間集計 |
| 勤怠データCSV（取込用） | CSV | スタッフナビゲーターの勤怠データCSVファイル取込形式（41項目・Shift_JIS） |

## 5. スタッフナビゲーターに合わせた点

スタッフナビゲーターのマニュアル（`提供資料\スタッフナビゲーター_マニュアル.pdf`）をもとに、帳票・CSV・用語を次のように合わせています。

### 5-1. 賃金台帳（マニュアル P593〜597「8 賃金台帳」）

- **様式**：スタッフ1人につき1枚。**1月〜12月を横に並べ、右端に給与計（年間合計）**を置く、スタッフナビゲーターの「賃金台帳」サンプルと同じ構成です。
- **ヘッダ**：ｽﾀｯﾌNo（8桁）、ｽﾀｯﾌ名、性別、生年月日、税区分、入社日、退社日、事業所名、出力日時、PAGE。
- **行の上部**：支払日・対象期間。
- **項目と並び順**：スタッフナビゲーターの賃金台帳と同じです。

| 区分 | 項目 |
|---|---|
| 日数 | 出勤日数、欠勤日数、休出日数、有給日数、遅早日数、特休／休２、休３／休４ |
| 時間 | 基本時間、普通残時間、深夜時間、深夜残時間、休出時間、その他時間外、有給時間、遅早 |
| 支給 | 基本、普通残、深夜、深夜残、休出、その他時間外手当、有給手当、交通費非課税、交通費課税、遅早控除、欠勤控除、休暇手当、休暇控除、その他課税、その他非課税 |
| 支給計 | 課税支給額、非課税支給額、総支給額、雇用保険対象額 |
| 社会保険 | 扶養家族人数、健康保険、介護保険、厚生年金、厚生年金基金、雇用保険、社保合計 |
| 税 | 課税対象額、所得税、年調過不足額、住民税、控除 |
| 合計 | 総控除額、差引支給額 |

- **CSV出力**：スタッフナビゲーターの「賃金台帳CSVファイル出力形式」（P596〜597）と同じ項目・順番・形式です（時間は「時間:分」、金額はカンマなし、日付は「西暦年/月/日」、文字コードはShift_JIS）。
  - オプション導入時だけ出力される「スタッフ種別」「前払金」は出力していません。

### 5-2. 勤怠データCSV（マニュアル P613〜615「14 勤怠データCSVファイル取込」）

補正後の勤怠を、スタッフナビゲーターに取り込める形式（全41項目）で出力します。

- スタッフ番号、受注番号（0＝スタッフの受注が1つ）、締日、出勤日数〜有給日数、基本時間〜有給時間、45H超過・60H超過の各時間、休暇区分No.1〜4日数
- 1か月の時間外（普通残＋深夜残）が45時間・60時間を超えた分は、「45H超過－普通残」「60H超過－普通残」に出力します。

### 5-3. 用語・時間の区分

- **社員番号 → スタッフ番号**：スタッフナビゲーターと同じく **1〜8桁の数字** にしました（デモでは 1001〜1018）。取込CSVの項目名も「スタッフ番号」です（以前の「社員番号」でも読み込めます）。
- **時間の区分**：スタッフナビゲーターの単価区分に合わせ、重ならないように分けています。

| 区分 | 内容 |
|---|---|
| 基本時間 | 1日8時間以内で、深夜以外の時間 |
| 普通残時間 | 1日8時間を超えた時間のうち、深夜以外 |
| 深夜時間 | 1日8時間以内で、22時〜5時の時間 |
| 深夜残時間 | 1日8時間を超えた時間のうち、22時〜5時 |
| 休出時間 | 休日出勤の労働時間 |
| 有給時間 | 有給日数 × 1日の有給時間（設定画面で変更可） |

- **締日・支払日**：末締・翌月25日払いとして表示しています（設定画面で支払日を変更できます）。

### 5-4. スタッフナビゲーターにない資料（本システムで作る資料）

- **勤務表（出勤簿）・勤務実績集計表**：スタッフナビゲーターは基本的に月ごとの合計（日数・時間）だけを持っています。日ごとのデータは「タイムシートオプション」を導入した場合だけです。日ごとの始業・終業・休憩を記録した出勤簿は、本システムで作ります。
- **労働者名簿**：スタッフナビゲーターの「労働者名簿EXCEL出力」（P388〜390）で作れるため、本システムには入れていません。

### 5-5. 合わせていない点（本開発で決めること）

- **金額の計算**：デモ用の簡易計算です。本開発では、スタッフナビゲーターの給与計算結果（賃金台帳CSV）を取り込んで使う方式を想定しています。
- **遅早・特別休暇・その他課税など**：デモデータに元の情報がないため「0」で出力しています。
- **日ごとの勤怠データの入手元**：先方がタイムシートオプションを導入しているかどうかで変わるため、打ち合わせで確認が必要です。

## 6. デモデータを元に戻す

「設定」画面の **「デモデータを初期化」** を押すと、取込データ・補正履歴・操作ログ・設定をすべて削除し、デモ開始時の状態（7月・8月分を取込済み）に戻ります。

データは `StaffNavi/App_Data` に JSON 形式で保存されています（データベースは使っていません）。
このフォルダを削除しても、次回起動時に初期状態で自動的に作り直されます。
